I.N.D.R.A. - Intelligent Network Data ROI Analytics
User Manual & Project Documentation

1. PROJECT OVERVIEW
--------------------------------------------------------------------------------
INDRA is a futuristic, real-time data analytics system built to monitor and 
analyze marketing campaign effectiveness across multiple channels (Email, Social 
Media, Paid Ads). 

Inspired by the JARVIS/Tony Stark HUD aesthetic, it features a backend powered 
by Python/FastAPI that generates and streams live data, paired with a dynamic 
frontend using HTML/CSS/JavaScript and Plotly.js for interactive visualizations.


2. SYSTEM ARCHITECTURE
--------------------------------------------------------------------------------
The project is divided into two main components:
- BACKEND (FastAPI, Pandas, Scipy, Scikit-Learn)
- FRONTEND (HTML, CSS, JS, Plotly.js)

Directory Structure:
d:\NEW\INDRA\
├── backend\
│   ├── main.py.......... FastAPI server, API endpoints, background data simulator
│   └── analytics.py..... Core analytics engine (ROI calc, A/B Testing, ML models)
├── frontend\
│   ├── index.html....... Main dashboard HTML featuring glassmorphism layout
│   ├── style.css........ Dark theme, neon glows, CRT scanlines, CSS animations
│   └── script.js........ Data polling, logic, and Plotly chart configuration
├── requirements.txt..... Python dependencies list
└── user_manual.txt...... This file


3. CORE FEATURES
--------------------------------------------------------------------------------
* Real-Time Dashboard Simulation
  The backend features a background generator that creates simulated marketing 
  metrics (impressions, clicks, conversions, cost, revenue) every 2 seconds. 
  The frontend polls these updates to animate the holographic HUD interface 
  in real-time.

* A/B Testing Engine
  Using SciPy, INDRA dynamically evaluates variant A vs. variant B conversion 
  rates, calculating the t-statistic and p-value to determine a statistically 
  significant winner.

* AI & Predictive Modeling
  Utilizing Scikit-Learn (LinearRegression), the system learns from historical 
  data to predict expected ROI for future campaigns based on cost, clicks, and 
  conversions. It also generates intelligent directives, suggesting which 
  channels to scale or pause based on real-time ROI trends.

* JARVIS Visualization Theme
  The frontend applies an immersive sci-fi aesthetic leveraging CSS grid, 
  glow text effects, rotating arc reactor animations, and automated terminal 
  log scrolling. Plotly.js charts are custom-styled to integrate seamlessly 
  with the dark cyan color scheme.


4. HOW TO RUN INDRA
--------------------------------------------------------------------------------
Step 1: Install Dependencies
Open your terminal (PowerShell), navigate to the project directory, and install 
the required Python modules:
> cd d:\NEW\INDRA
> pip install -r requirements.txt

Step 2: Start the Backend Server
IMPORTANT: You must run the server using Uvicorn. Executing main.py directly 
with Python will cause module import errors. Run the following command from the 
INDRA directory:
> cd d:\NEW\INDRA
> python -m uvicorn backend.main:app --port 8000 --reload

Wait until you see the message: "Application startup complete." The backend API 
will now be alive and streaming data at http://127.0.0.1:8000.

Step 3: Launch the Dashboard
Open the index.html file in your preferred web browser. 
> d:\NEW\INDRA\frontend\index.html 

You should now see the I.N.D.R.A HUD interface receiving telemetry from the 
FastAPI backend!


5. TROUBLESHOOTING
--------------------------------------------------------------------------------
Error: ModuleNotFoundError: No module named 'backend'
Cause: Trying to run `python d:/NEW/INDRA/backend/main.py` directly.
Fix: Use Uvicorn module execution from the root INDRA directory:
`cd d:\NEW\INDRA`
`python -m uvicorn backend.main:app --port 8000 --reload`

Error: Connection Refused / Terminal says "WAITING FOR TELEMETRY"
Cause: The frontend cannot connect to the backend server.
Fix: Ensure Step 2 is completed, the server is running on port 8000, and 
there are no errors in the backend terminal console.
